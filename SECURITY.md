# Sicherheitshinweise & Vulnerability Reporting

Sicherheit und der Schutz persönlicher Daten haben bei SecretWish höchste Priorität.

## Sicherheitslücken melden

Wenn du eine Sicherheitslücke in SecretWish entdeckst, melde diese bitte **verantwortungsbewusst (Responsible Disclosure)** und erstelle kein öffentliches GitHub Issue.

### Kontakt:
- E-Mail: `security@secretwish.local` oder erstelle ein privates Security Advisory auf GitHub.
- Bitte gib eine detaillierte Beschreibung der Lücke, Schritte zur Reproduktion und ggf. einen Proof of Concept an.

Wir bemühen uns, Berichte innerhalb von 48 Stunden zu sichten und schnellstmöglich einen Patch bereitzustellen.
